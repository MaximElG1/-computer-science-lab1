# Лабораторная работа №4

## Анализ учебного набора данных с помощью SQL

**Цель работы:** научиться исследовать связанную базу данных образовательной платформы с помощью SQL, выполнять фильтрацию, агрегирование и соединение данных, проверять корректность результатов и формулировать выводы.

**Вариант:** 9

**Набор данных:** учебная база образовательной платформы, содержащая сведения об учебных группах, студентах, преподавателях, курсах, записях на курсы и итоговых оценках.

**Краткое описание:** изучена структура шести связанных таблиц; выполнены запросы с `WHERE`, `ORDER BY`, агрегатными функциями, `GROUP BY`, `HAVING`, `INNER JOIN` и `LEFT JOIN`; проверены значения оценок и связи между результатами и записями на курсы. В индивидуальном исследовании рассчитана доля оценок от 90 баллов включительно по каждой учебной группе.

Подробные запросы, результаты и выводы приведены в файле [report/analysis.md](report/analysis.md).
