# Анализ информационной системы Т-Банка

## 1. Описание цифрового сервиса

**Название:** Т-Банк

**Ссылка:** https://www.tbank.ru/

**Вариант:** 9

### Назначение

Т-Банк — цифровой финансовый сервис, предоставляющий пользователям банковские и другие финансовые продукты через веб-интерфейс и мобильное приложение.

В рамках лабораторной работы исследуется публичная часть сайта, посвящённая дебетовым картам.

### Целевая аудитория

Основными пользователями сервиса являются физические лица, которые используют банковские продукты и дистанционные цифровые сервисы.

### Основные возможности

- просмотр информации о банковских продуктах;
- изучение условий дебетовых и других карт;
- оформление заявки на банковский продукт;
- работа с личным кабинетом;
- получение информации о доступных услугах и предложениях.

### Выбранный сценарий

Изучение публичной информации о дебетовой карте и формы заявки на её оформление.

## 3. Исследование клиентской части

Для исследования клиентской части использовались инструменты разработчика браузера Chrome DevTools.

### HTML

В разделе Elements была исследована HTML-структура формы.

В структуре страницы обнаружены элементы `div`, `label`, `fieldset` и другие HTML-элементы, используемые для построения формы и элементов управления.

Элементы формы имеют CSS-классы и атрибуты `data-*`, используемые клиентской частью для идентификации компонентов интерфейса.

### CSS

В DevTools были обнаружены подключённые CSS-правила, отвечающие за:

- размеры элементов;
- отступы;
- отображение текста;
- границы;
- расположение элементов;
- внешний вид элементов формы.

### JavaScript

Клиентская часть использует JavaScript для обработки действий пользователя и взаимодействия с серверной частью.

В DevTools Network были обнаружены запросы типа `fetch` и другие сетевые обращения, выполняемые браузером при работе страницы.

## 4. Исследование сетевого взаимодействия

Для исследования сетевого взаимодействия использовался раздел Network в Chrome DevTools.

При загрузке страницы браузер выполняет множество сетевых запросов для получения HTML, JavaScript, CSS, изображений и других ресурсов.

Также были обнаружены запросы к серверной части Т-Банка.

### Исследованный запрос

Один из обнаруженных запросов:

| Параметр | Значение |
|---|---|
| Метод | POST |
| URL | `https://www.tbank.ru/api/stat.../gateway/v1/events` |
| Статус | 204 No Content |
| Тип | Fetch/XHR |

Данный запрос относится к взаимодействию клиентской части с серверной инфраструктурой и демонстрирует передачу данных от браузера на сервер.

Статус `204 No Content` означает, что сервер успешно обработал запрос, но не возвращает содержимое ответа.

В ходе исследования реальные банковские операции и отправка заявки не выполнялись.

## 5. Серверная часть и внешние сервисы

Серверная часть информационной системы необходима для обработки запросов пользователей, хранения и обработки данных, а также предоставления информации клиентской части.

Предполагаемые основные серверные компоненты:

| Компонент | Назначение |
|---|---|
| Web-сервер | Обработка запросов браузера |
| API | Обмен данными между клиентской и серверной частью |
| Серверная логика | Обработка пользовательских действий |
| База данных | Хранение информации, необходимой для работы сервиса |
| Система аналитики | Сбор статистики взаимодействия пользователей с интерфейсом |

Некоторые серверные компоненты невозможно непосредственно увидеть через браузер. Поэтому их наличие является архитектурным предположением, основанным на характере работы современного цифрового сервиса.

## 6. Пользовательский сценарий

Рассматриваемый сценарий — изучение дебетовой карты и формы заявки.

Последовательность работы:

1. Пользователь открывает сайт Т-Банка.
2. Браузер загружает страницу цифрового сервиса.
3. Клиентская часть отображает информацию о дебетовой карте.
4. Пользователь изучает условия продукта.
5. Пользователь открывает форму оформления карты.
6. Интерфейс отображает поля для заполнения.
7. Пользователь может выбрать дизайн карты и параметры продукта.
8. Клиентская часть обрабатывает действия пользователя.
9. При необходимости браузер выполняет сетевые запросы к серверу.
10. Сервер обрабатывает полученные запросы.
11. Результат обработки отображается в интерфейсе.

В рамках лабораторной работы заполнение и отправка реальной заявки не выполнялись.
