# -computer-science-lab1
# Лабораторная работа №1

## Анализ устройства современной информационной системы

### Цель работы

Получить представление об устройстве современной информационной системы на примере реального цифрового сервиса, исследовать пользовательский интерфейс, клиентскую и серверную части, сетевое взаимодействие и основные компоненты системы.

### Выбранный цифровой сервис

**Название:** Т-Банк

**Вариант:** 9

**Ссылка:** https://www.tbank.ru/

**Тип:** финансовый цифровой сервис

### Выбранный пользовательский сценарий

Изучение публичных банковских продуктов и формы заявки на дебетовую карту.

В рамках работы была исследована публичная часть сайта Т-Банка, интерфейс страницы продукта и форма заявки. С помощью инструментов разработчика браузера были изучены HTML-структура страницы и сетевое взаимодействие.

### Результат работы

В ходе лабораторной работы:

- изучен пользовательский интерфейс Т-Банка;
- определены основные компоненты информационной системы;
- исследована HTML-структура страницы с помощью DevTools;
- изучены сетевые запросы в разделе Network;
- рассмотрено взаимодействие клиентской и серверной частей;
- описан пользовательский сценарий;
- разработана архитектурная схема информационной системы;
- подготовлен подробный отчет с результатами исследования.
